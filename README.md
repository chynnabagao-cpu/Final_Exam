# Student Information Management System
**Final Examination Project**

## Project Description
A complete Node.js web application for managing student records, demonstrating full CRUD operations, cloud database integration with Aiven, and deployment via Render.

## Deployment Link
- **Live Application:** [PASTE_YOUR_RENDER_URL_HERE]

## Technologies Used
- **Backend:** Node.js, Express.js
- **Database:** MySQL (Hosted on Aiven Cloud)
- **Deployment:** Render
- **Version Control:** GitHub

## Features
- Add new student records
- View list of registered students
- Update student details
- Remove student records from the database

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Configure environment variables (`DB_HOST`, `DB_USER`, etc.) in your environment.
4. Run `npm start` to launch locally.
